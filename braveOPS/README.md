# BraveOps — MantraLab v3.0
Configuration durcie du navigateur Brave pour opérations cyber-défense.

## Objectifs
- Durcissement maximal du navigateur
- Cloisonnement OSINT / GitOps
- Protection contre fingerprinting
- Compatibilité totale GitHub / SLSA

## Contenu
- brave-hardening.json
- brave-policies.json
- brave-extensions.md
- brave-profile.md

## Mode d’emploi
Importer les fichiers dans Brave via :
- brave://settings
- brave://policy
- brave://extensions
