MantraLab — Discipline Avancée
==============================

Objectifs :
- Renforcer la rigueur des commits
- Garantir une traçabilité totale
- Imposer une structure militaire stricte

Règles avancées :
- Aucun commit sans justification technique
- Aucun commit sans impact mesurable
- Aucun commit sans signature complète
- Aucun commit sans conformité aux packs .config/

MantraLab — Sécurité Git Avancée
================================

Contrôles :
- Analyse des fichiers modifiés
- Détection des patterns réseau sensibles
- Interdiction des dumps mémoire
- Interdiction des captures réseau brutes
- Interdiction des binaires non signés

Tous les commits sont soumis au hook de sécurité réseau.

MantraLab — Conformité Avancée
==============================

Normes :
- Respect strict de .editorconfig
- Respect strict de .gitattributes
- Respect strict de .gitignore
- Respect strict des licences MantraLab‑1.0

Tout commit non conforme est automatiquement rejeté.

MantraLab — Audit Avancé
========================

Chaque commit doit inclure :
- Impact opérationnel
- Module affecté
- Justification technique
- Signature complète

Les audits sont stockés dans : .git/audit/

MantraLab — Opérations Git Avancées
===================================

Branches opérationnelles :
- ops/core/
- ops/tools/
- ops/scripts/
- ops/docs/
- ops/manifests/

Chaque opération doit être validée par un commit SEC ou OPT.
