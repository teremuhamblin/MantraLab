MantraLab — GitOps Pack
=======================

Le pack GitOps de MantraLab fournit les outils nécessaires pour automatiser la
discipline, l’audit et la synchronisation du dépôt.

Contenu :
- OPTION workflows/ : automatisation GitHub Actions
- ops/ : scripts opérationnels
- OPTION manifests/ : documentation GitOps

Objectifs :
- Automatiser la discipline Git
- Assurer un audit continu
- Synchroniser les modules MantraLab
- Renforcer la sécurité du dépôt
